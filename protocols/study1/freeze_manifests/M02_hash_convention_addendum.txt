Explanation:
The freeze manifest used `shasum -a 256`, which hashes the exact file bytes,
including the final newline.

The runner loads source files with:
    path.read_text(encoding="utf-8").strip()

It therefore hashes and submits the same source text after removing only
leading and trailing whitespace.

The Trial 1 logged hash exactly matches SHA-256(M02.txt.strip()).

Conclusion:
M02 Trial 1 used the content of the frozen M02 source packet. The hash
difference reflects two documented hashing conventions, not different
substantive source content.
